📖 Panduan Lengkap Instalasi ke Google Apps Script (GAS)
  1. Buat Spreadsheet Baru: Buka sheets.new di browser Anda. Beri nama misal: "Threads Formula Lab DB".
  2. Buka Script Editor: Klik menu Extensions → Apps Script.
  3. Buat File Script: Buat file dengan nama-nama berikut di Apps Script editor:
    • Code.gs
    • Database.gs
    • AI.gs
    • Prompts.gs
    • Formula.gs
    • Index.html
    • CSS.html
    • JS.html
  4. Tempel Kode: Salin masing-masing kode yang telah disediakan di lab ini ke file yang bersangkutan.
  5. Jalankan Setup Database: Pilih fungsi setupDatabase di dropdown toolbar Apps Script, lalu klik Run. Berikan izin otorisasi akses Google Sheets.
  6. Konfigurasi API Key Gemini: Klik ikon gerigi Project Settings di bilah kiri Apps Script → scroll ke Script Properties → klik Add script property → isi GEMINI_API_KEY dengan API Key Gemini Anda.
  7. Deploy Web App: Klik tombol biru Deploy di kanan atas → New deployment → pilih tipe Web app:
    • Execute as: Me
    • Who has access: Anyone
    Klik Deploy dan buka link Web App yang dihasilkan!
